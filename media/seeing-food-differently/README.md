# Seeing Food Differently — Evidence Library

**Status:** Permanent project asset. Seed structure only. Few or no files yet is fine.  
**Design rules:** `docs/seeing-food-differently-design-constitution.md` § Evidence library · § Visual teaching

## Purpose

Store teaching evidence, not pretty pictures.

Every asset should answer: *What does this help someone notice, understand, or remember?*

## Folders

| Folder | Use for |
|--------|---------|
| `comparisons/` | Side-by-side outcomes (two tomatoes, two methods, early vs late taste documentation) |
| `ingredients/` | Close-ups of state, variety, ripeness, structure |
| `kitchen/` | Process and tools when they teach (board, pan, tadka, dough rest) |
| `garden/` | Harvest as evidence of variety/state, not scenery |
| `people/` | Only with clear teaching value and permission |
| `diagrams/` | Teaching illustrations (including AI diagrams that never pretend to be photos) |
| `experiments/` | Try-tonight documentation |
